Do Not Update A Rank Until

  1. The activity is clear: Solo, Dungeon, Raid, 1v1 PvP, Small PvP, Large PvP or Beginner.
  2. The page can state the Global patch and last tested date.
  3. The claim has repeatable evidence or a clearly labeled official source.
  4. The update log records what changed and why.

Update Order

1. Release Date / StatusConfirm access, server status and any launch delay.
2. ClassesConfirm roster, role labels and class page basics.
3. BuildsFill skill values and early stat priorities only after client checks.
4. Tier ListsMove TBD to ranks only where activity-specific evidence exists.
5. DungeonsCreate individual dungeon pages only after name, mechanics and rewards are verified.
