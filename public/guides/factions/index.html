Confirmed Global Faction Context

Official Global maintenance notices name both Elyos and Asmodian areas. Current server and character-creation restrictions can change with population, so the client and official notices remain the source of truth for what can be created now.

Choose Without Regret

  1. Agree on region, server and faction with friends or guildmates before character investment.
  2. Check the client for current creation or recommendation labels at the moment you create.
  3. Do not assume characters on different factions can group, trade or transfer together unless the Global client explicitly permits it.
  4. Review the server guide before relying on a planned transfer; the announced October 14 system has restrictions and is not yet live.
