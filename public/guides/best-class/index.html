How To Choose Before Global Meta Exists

  1. Pick by role first: tank, healer, support, ranged damage, melee pressure or summoner.
  2. Pick by tolerance for responsibility: Templar and Cleric may carry more group expectations.
  3. Pick a backup class for advance access because balance and queue demand can change quickly.
  4. Wait for Global Verified tier updates before treating a class as best for a specific activity.
