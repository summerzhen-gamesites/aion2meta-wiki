Who Should Play This Class

Choose Sorcerer if you want ranged magical burst, deliberate cast windows and planned control.

Likely strengths

Clear burst-caster identity; ranged visibility; control can protect a planned damage window.

Tradeoffs to accept

Interrupted or unsafe casts reduce output sharply; poor positioning leaves few answers at close range.

How To Play It

Dungeon / group

PvE

Plan casts around movement, hold burst for stable windows and move early rather than cancel late.

Matchup framework

PvP

Create space, wait out interrupts and commit burst only when the target cannot deny the sequence.

Progression

Solo

Open with control or range, finish priority enemies first and save repositioning for failed control.

Core decision loop

Pre-position → setup/control → cast burst → use low-commitment pressure while recovering → relocate.

First Session Checklist

  1. Learn the range and movement needed for the class job: Burst caster DPS.
  2. Identify one pressure sequence, one defensive response and one escape or reposition option.
  3. Test the loop on ordinary enemies before judging dungeon or PvP performance.
  4. Open the Sorcerer build and choose the correct activity variation.
  5. Record Global patch and tested activity before treating performance as evidence.
