Who Should Play This Class

Choose Ranger if you want physical ranged pressure, active spacing and safe attack opportunities while moving.

Likely strengths

Ranged access; kiting identity; flexible target switching and clear mechanic visibility.

Tradeoffs to accept

Poor spacing erases the range advantage; control and movement must be planned.

How To Play It

Dungeon / group

PvE

Use range to keep uptime, pre-position for the next safe lane and stay within group support.

Matchup framework

PvP

Create distance before committing damage, deny approaches and switch targets when a chase breaks position.

Progression

Solo

Open from range, slow the approach and move toward cleared ground; save an escape for failed control.

Core decision loop

Open at range → establish spacing/control → pressure while moving → disengage from contact → reopen.

First Session Checklist

  1. Learn the range and movement needed for the class job: Ranged physical DPS.
  2. Identify one pressure sequence, one defensive response and one escape or reposition option.
  3. Test the loop on ordinary enemies before judging dungeon or PvP performance.
  4. Open the Ranger build and choose the correct activity variation.
  5. Record Global patch and tested activity before treating performance as evidence.
