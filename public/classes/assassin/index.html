Who Should Play This Class

Choose Assassin if you enjoy target selection, positional play and short commitment windows where timing matters most.

Likely strengths

Focused melee burst identity; rewards planning, movement and recognizing exposed targets.

Tradeoffs to accept

Punishing when an engage is mistimed; vulnerable to control and forced downtime.

How To Play It

Dungeon / group

PvE

Maintain positional access, prepare resources before burst and avoid losing a full sequence to mechanics.

Matchup framework

PvP

Find an exposed target, force a defensive response and leave before counter-control arrives.

Progression

Solo

Control pull size and prioritize clean kills; mobility is part of survival, not only damage uptime.

Core decision loop

Prepare resources → approach safely → apply setup/control → commit burst → disengage or reset.

First Session Checklist

  1. Learn the range and movement needed for the class job: Burst DPS / pick pressure.
  2. Identify one pressure sequence, one defensive response and one escape or reposition option.
  3. Test the loop on ordinary enemies before judging dungeon or PvP performance.
  4. Open the Assassin build and choose the correct activity variation.
  5. Record Global patch and tested activity before treating performance as evidence.
