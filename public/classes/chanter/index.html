Who Should Play This Class

Choose Chanter if you want to improve a party through buffs and utility while still contributing direct damage.

Likely strengths

Hybrid support identity; adapts between contribution and recovery; rewards group awareness.

Tradeoffs to accept

Value is wasted when buffs or recovery are mistimed; personal output misses support contribution.

How To Play It

Dungeon / group

PvE

Maintain valuable group effects, deal damage during stable periods and reserve utility for predictable pressure.

Matchup framework

PvP

Stay close enough to support allies without becoming an easy focus; extend engages or blunt burst.

Progression

Solo

Balance damage with sustain to reduce downtime; do not copy a group setup that cannot finish solo fights.

Core decision loop

Establish buffs → contribute damage → watch allies and enemy setup → respond with utility/recovery → refresh effects.

First Session Checklist

  1. Learn the range and movement needed for the class job: Buff support / hybrid.
  2. Identify one pressure sequence, one defensive response and one escape or reposition option.
  3. Test the loop on ordinary enemies before judging dungeon or PvP performance.
  4. Open the Chanter build and choose the correct activity variation.
  5. Record Global patch and tested activity before treating performance as evidence.
